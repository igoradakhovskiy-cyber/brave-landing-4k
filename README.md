# BRAVE — лендинг «4 компетенції»

Финальный лендинг для Украины и украинцев в ЕС (09.10.2026). Один файл `index.html` (CSS и JS внутри) и папка `assets/`: шрифты Geologica и Onest (OFL), intl-tel-input, логотипы, фото основателя и свидетельства, портреты клиентов с официального сайта.

Тексты — по утверждённому прототипу `../11_brave_landing_4k_prototype.md`. Логика квиза совпадает с `../brave-quiz-4k/index.html`.

## Настройки (вверху главного скрипта)
| Переменная | Что делает |
|---|---|
| `SUBMIT_URL` | Вебхук CRM (POST JSON). Пусто — заявка уходит только в консоль и `dataLayer` |
| `PIXEL_ID` | Meta Pixel BRAVE `1669140901889164`. Грузится сразу у всех посетителей. Cookie-баннера и галочки согласия нет (решение 09.10) |

## Режимы проверки
- `?review=1` — оранжевой рамкой подсвечено всё, что ждёт подтверждения команды (наведите курсор — появится подсказка);
- `?test=sasha|it|family|dmytro|kyrylo|strong` — сразу показывает результат квиза для тест-профиля;
- `?pixel=1` — включает пиксель на localhost. По умолчанию локальное превью и открытие файла в Meta ничего не шлют.

## Заявка
Единственное действие после квиза — заявка на розбір. Менеджер связывается, уточняет запрос и время, затем назначается встреча с радником. Разбор в мессенджер не отправляем.

Одна разметка формы в трёх местах: форма прямо под результатом квиза, модалка на остальные CTA и форма в финале. Поля:
- имя;
- телефон — intl-tel-input, код страны по IP, проверка номера, E.164;
- мессенджер (Telegram, WhatsApp, Viber или звонок), время звонка — только при звонке.

Если квиз пройден, в заявку уходит блок `quiz`: ответы, уровни, скрытые баллы и перекосы, резюме, пункты «Як радник допоможе» и повестка встречи — чтобы менеджер понял запрос, а радник подготовился. Источник заявки — в поле `source`: `quiz_book` (форма под результатом), `header`, `hero`, `free`, `final`, `sticky`.

**В Meta не уходит ничего финансового.** Отправляются только `Lead` (с `eventID` для будущей дедупликации с CAPI) и пользовательские события `quiz_start`, `quiz_step`, `quiz_complete`, `lead_form_open`, `cta_click`, `faq_open`.

## Кейсы — правило
Кейсы полностью обезличены: только роль и ситуация. Без имён, возраста, стран, переезда и имён радників. Клиенты, чьи ситуации описаны в кейсах, на стену портретов не попадают.

## Открытые вопросы
1. **Вебхук CRM в `SUBMIT_URL`.** Пока он пустой, Meta получает событие `Lead`, а имя и телефон никуда не уходят.
2. SLA ответа менеджера («протягом робочого дня»).
3. [ЮРИСТ] для ЕС: работа с местными бухгалтерами, инвестиционная часть, формат для резидентов ЕС.
4. Подтвердить: формат совместного разбора для пары, формулировку «щокварталу ви оцінюєте роботу радника».
5. Цифры точки Б в кейсе семьи с франшизой — ждём объяснения от команды.
